Описание
Данное приложение представляет собой графическую программу на языке Python, использующую библиотеку Tkinter, для генерации случайных задач. Пользователь может добавлять новые задачи с указанием их типа (учёба, спорт, работа), просматривать историю выполненных задач и фильтровать историю по типу задач. При нажатии на кнопку "Сгенерировать задачу" программа случайным образом выбирает задачу из текущего списка с учетом выбранного фильтра, отображает ее и сохраняет в историю. Также реализована возможность сохранения и загрузки задач и истории из файлов tasks.json и history.json соответственно.
Возможные тесты и примеры использования

Запуск программы:После запуска откроется окно с интерфейсом.

Добавление новой задачи:  

Введите название задачи в поле "Добавить новую задачу".  
Выберите тип задачи из выпадающего списка ("учёба", "спорт", "работа").  
Нажмите кнопку "Добавить задачу".  
После этого задача добавится в список задач и историю.


Генерация случайной задачи:  

Нажмите кнопку "Сгенерировать задачу".  
В окне появится случайная задача из текущего фильтра.  
Эта задача будет добавлена в историю.


Фильтрация истории:  

Выберите из выпадающего списка фильтр ("Все", "учёба", "спорт", "работа").  
В истории отображаются только задачи соответствующего типа.


Перезагрузка программы:  

Все задачи и история сохраняются между сессиями.  
После перезапуска программа продолжит работу с сохраненными данными.
