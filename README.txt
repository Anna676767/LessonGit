Общая информация
Программа предназначена для ведения дневника погоды. Вы можете добавлять новые записи о погоде, фильтровать их по дате и температуре, а также просматривать сохранённые данные.

Как добавить новую запись

Введите дату в формате дд.мм.гг (например, 25.12.23) в поле "Дата(дд.мм.гг)".

Введите температуру в числовом виде в поле "Температура(число)".

Введите описание погоды (например, "солнечно", "дождь") в поле "Описание погоды".

Укажите наличие осадков:

Введите да, если есть осадки.
Введите нет, если осадков нет.


Нажмите кнопку "Добавить запись". После этого запись сохранится в файл данных, и все поля очистятся для новой записи.



Как просмотреть записи с фильтрацией

Введите дату, по которой нужно фильтровать, в поле "Фильтр по дате" (можно оставить пустым, чтобы не фильтровать по дате).

Введите температуру, по которой нужно фильтровать, в поле "Фильтр по температуре" (можно оставить пустым, чтобы не фильтровать по температуре).

Нажмите кнопку "Показать отфильтрованные записи". Внизу появится список подходящих записей или сообщение "Записей нет", если подходящих данных нет.



Важные замечания

Формат даты должен быть: дд.мм.гг (например, 01.01.24).
Температура должна быть числом без дополнительных символов.
В поле "Осадки" ввести нужно да или нет.
Все данные сохраняются в файл .venv/weather.json. Убедитесь, что этот файл существует или программа сможет создать его автоматически при первой записи.


Возможные ошибки и их исправление

Неверный формат даты: убедитесь, что дата введена в формате дд.мм.гг.
Неверный формат температуры: введите число без букв или символов.
Пустое описание погоды: введите описание погоды.
Неверное значение осадков: введите либо да, либо нет.
При фильтрации по температуре: убедитесь, что вводите число.
